That day at the shop: opening hours across, confirmed bookings as pale `accent` blocks, the request under decision as a dashed `accent` outline.

- An inline SVG, `viewBox 0 0 640 56`, scaled to the column. Hour ticks every 60 minutes with 11px labels in `muted`; the axis is a 1px `rule` line.
- `.busy` blocks are `accent` at 22% opacity, radius 3, labelled inside with the pet's name when wider than 60px. `.this` is a `sheet` fill with a 1.5px dashed `accent` stroke, labelled with its start time in `accent`.
- No gridlines, no legend chrome beyond the two-item `.legend` under it. If the request overlaps a confirmed block the legend adds one sentence in `declined`.
- A closed day shows one sentence instead of the strip. This is the screen's one chart hue on its one data element.
