A booking's state as a small pale pill: the only colour on a list row.

- `.pill.pill-pending` (`pending` on `pending-bg`): the agent held it and nobody has decided. The one thing to do on the screen, so it is the warmest of the three.
- `.pill.pill-confirmed` (`confirmed` on `confirmed-bg`), `.pill.pill-declined` (`declined` on `declined-bg`; cancelled uses the same pair).
- `.pill.pill-neutral` (`ink` on `neutral-bg`) for tags that are not a state: the channel, a size tier, "Corrected".
- 20px tall, `radius-pill`, text in `pill` (12/16 at 500), sentence case. All text pairs reach 4.5:1 on their fill. Never a dot plus a word, never an icon.
